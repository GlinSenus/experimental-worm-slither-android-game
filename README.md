# experimental-worm-slither-android-game
Old experimental android game similar to Slither.io, using a simple Android 2D game framework with SurfaceView and Canvas. All graphics are drawn using java codes. This simple game project was created back in 2018 for self-learning purposes and was recently fixed and updated.
